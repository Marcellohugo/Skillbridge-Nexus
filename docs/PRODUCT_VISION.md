# Visi Produk & Repositioning

Dokumen ini menjelaskan arah strategis SkillBridge Nexus: dari competency intelligence yang awalnya terasa fokus ke informatika, menjadi **Pathway Readiness Platform** lintas jenjang dan lintas pathway. Dokumen ini menjadi rujukan saat menulis fitur baru, materi pitch, atau rencana ekspansi pasar.

## Masalah Yang Diselesaikan

| Masalah | Dampak |
|---|---|
| Siswa SMA bingung memilih jurusan/jalur setelah lulus | Salah jurusan, drop out, beasiswa terlewat |
| Siswa SMK belum siap memasuki dunia kerja meski sudah lulus | Lama menganggur, mismatch industri |
| Mahasiswa awal tidak tahu cara menabung skill untuk magang | Magang berkualitas rendah, IPK turun |
| Mahasiswa akhir & fresh graduate sulit menerjemahkan IPK ke kesiapan kerja | Lamaran ditolak, percaya diri turun |
| Lulusan SMA non-kuliah tidak mendapat panduan jalur sertifikasi atau wirausaha | Stagnan di pekerjaan informal tanpa progres |
| Career switcher kesulitan memetakan transferable skill | Pivot lama, ekonomi tertekan |
| Pekerja awal sulit naik ke jenjang berikutnya | Stuck di level entry |
| Sekolah, kampus, dan dinas pendidikan kekurangan visibility readiness siswa | Intervensi telat, blind spot kurikulum |
| Mentor industri tidak punya wadah berkontribusi terstruktur | Mentor potensial tidak terlibat |
| Recruiter sulit menemukan kandidat berbasis evidence | Bias kredensial, talenta terabaikan |

## Target User

| Segmen | Pathway Utama | Catatan |
|---|---|---|
| Siswa SMA | Masuk kuliah, beasiswa, sertifikasi | SNBT, jalur prestasi, motivation letter |
| Siswa SMK | Kerja entry-level, PKL, sertifikasi vokasi | Mismatch industri perlu dipetakan |
| Mahasiswa awal | Adaptasi kampus, magang awal | Manajemen waktu kuliah |
| Mahasiswa akhir | Magang, kerja entry-level, lanjut studi | Skripsi → portfolio |
| Fresh graduate | Kerja, sertifikasi, pivot pertama | First job dalam 6 bulan |
| Lulusan SMA non-kuliah | Kerja, sertifikasi, wirausaha mikro | Tanpa subsidi pendidikan tinggi |
| Career switcher | Pindah role / industri | Validasi transferable skill |
| Pekerja awal | Naik jenjang | Promotion gap, sertifikasi profesional |

## Repositioning: SkillBridge → Pathway Readiness

| Sebelum | Sesudah |
|---|---|
| Competency intelligence terasa fokus IT | Pathway readiness lintas jenjang |
| Career Role | Pathway Target (kuliah, beasiswa, magang, kerja, sertifikasi, wirausaha, pindah karier) |
| Skill Taxonomy IT-heavy | Readiness Taxonomy (Academic, Digital, Career, Vocational, Higher Education, Entrepreneurship, Life) |
| TRI (Talent Readiness Index) | TRI tetap untuk konteks karier; PRI (Pathway Readiness Index) untuk lintas pathway |
| Portfolio project | Evidence Bank lintas tipe |
| Mentor matching | Support Network matching (mentor, BK, dosen, alumni, orang tua, training provider, scholarship officer, employer, komunitas) |
| Mentor sebagai konsumen sesi | Mentor sebagai contributor materi dengan reward |
| Single dashboard learner | Multi-stakeholder dashboard (sekolah, kampus, employer, scholarship) |

Repositioning ini tidak menghapus nilai existing. TRI, mentor matching, portfolio, dan career intelligence tetap menjadi inti, namun cakupan diperluas agar produk relevan untuk segmen di luar informatika.

| Employer | Talent directory dengan evidence terverifikasi |
| Scholarship Officer | Eligibility score, learning barrier profile |

| Pemerintah | Indeks readiness regional, gap kurikulum, intervensi terbukti |
| Komunitas | Mentor pool, peer circle |

## Prinsip Produk

1. **Jujur tentang status fitur.** Implemented vs Recommended dipisahkan tegas.
2. **Evidence-first.** Setiap klaim readiness harus punya jejak data yang dapat ditelusuri.
3. **Explainable.** Skor readiness, match mentor, rekomendasi pathway harus bisa dijelaskan.
4. **Inclusive by default.** Aksesibilitas, i18n, low-bandwidth, plain language menjadi bagian inti.
5. **Privacy-aware.** Data pribadi, evidence, dan visibility employer dikontrol oleh user.
6. **Institution-friendly.** Sekolah dan kampus harus mendapat dashboard, bukan hanya learner.
7. **Mentor-empowering.** Mentor bukan hanya konsumen sesi; mentor membangun materi dan mendapat reward.
8. **Cross-pathway.** Bukan sekadar role IT; semua jenjang dan jalur berlaku.

## Outcome Yang Dicari

- Setiap user tahu pathway yang sedang dijalani dan langkah berikutnya.
- Setiap institusi tahu cohort mana yang berisiko dan kurikulum mana yang lemah.
- Setiap mentor tahu dampaknya, tidak hanya jumlah sesi.
- Setiap recruiter dapat menilai kandidat berdasarkan evidence terverifikasi.
- Equity readiness lintas wilayah dan latar belakang mengalami pengurangan gap.

## Diferensiasi

| Diferensiasi | Penjelasan |
|---|---|
| TRI + PRI | Skor readiness karier dan pathway dalam satu sistem |
| Explainable matching | Mentor & support network punya alasan terbaca |
| Evidence loop | Portfolio/Evidence Bank memengaruhi readiness, divalidasi mentor |
| Intervention queue | Risiko diterjemahkan menjadi tindakan terjadwal |
| Cross-pathway | Mendukung SMA, SMK, mahasiswa, lulusan SMA, fresh graduate, switcher, pekerja awal |
| Mentor Content Studio | Mentor membangun materi dengan reward berbasis dampak |
| Multi-stakeholder dashboard | Sekolah, kampus, employer, scholarship, pemerintah |
| Inclusive UX | Aksesibilitas, i18n, plain language, low bandwidth |
